# Security Policy

## Supported versions
Only the latest release receives fixes.

## Reporting a vulnerability
Please **do not** open a public issue for security problems. Use GitHub's private reporting:
**Security → Report a vulnerability** on this repository. Include steps to reproduce and the
impact. You can expect an acknowledgement within a week.

## Scope
win-disk-doctor is read-only and makes no network requests. Relevant reports include any way to
make it modify files, follow a link out of a checked location, or reveal real paths or file names
in its output.
